## 📌 Descripción

**Libre Mercado** es un clon funcional de la plataforma de comercio electrónico MercadoLibre. El objetivo del proyecto es recrear su funcionalidad esencial utilizando el stack PERN (PostgreSQL, Express, React, Node.js).

Actualmente incluye funcionalidades como:

- ✅ Creación de cuenta e inicio de sesión
- 🔍 Búsqueda y navegación de productos
- 🚚 Selección de método de entrega
- 💳 Pagos integrados con Stripe
- 🔐 Cierre de sesión

> 📌 Esta es la versión 1.0 y seguirá mejorando con nuevas funcionalidades como validaciones, historial de compras, favoritos, etc.
